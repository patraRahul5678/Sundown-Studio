# 🌇 Sundown Studio Clone

A responsive **frontend clone of the Sundown Studio website**, built as part of my journey to strengthen my understanding of **frontend development, responsive design, modern CSS techniques, and interactive animations**.

This project focuses on recreating the look, feel, and interactions of the original website using clean and optimized code while improving my skills in building pixel-perfect user interfaces.

> **Developed by Rahul Patra while learning advanced frontend development, responsive design, and animation techniques.**

---

## 🚀 Live Demo

👉 **[View Live Website](https://patrarahul5678.github.io/Sundown-Studio/)**

## 📌 Features

* 🎨 Pixel-perfect UI inspired by Sundown Studio
* 📱 Fully responsive design (mobile, tablet, and desktop)
* ✨ Smooth scrolling and interactive animations

## ⚙️ Installation & Setup

### 1. Clone the Repository

```bash
git clone https://github.com/patraRahul5678/Sundown-Studio.git
```

### 2. Navigate to the Project Folder

```bash
cd Sundown-Studio
```

### 3. Open the Project

Since this is a static frontend project, simply open the `index.html` file in your browser.

Alternatively, you can use the VS Code Live Server extension for a better development experience.
